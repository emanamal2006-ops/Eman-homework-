# Classical Conditioning — by Eman

A small browser game made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — colors, layout, responsive design
- `script.js` — game scenes and button behavior

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages section.

The game uses inline SVG drawings, so there are no image files or extra libraries to install. The title font loads from Google Fonts; the game still works if that font service is unavailable.
